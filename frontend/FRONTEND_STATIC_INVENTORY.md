# Frontend Static Inventory

Project: Greenland Business & Compliance

Purpose: this file records the current static Next.js frontend in enough detail to rebuild the content dynamically from a Laravel REST API. It lists every route, shared component, section, subsection, static data array, CTA, form field, link, image, placeholder, and known static issue found in the frontend source.

Source folder audited: `frontend/`

Audit date: 2026-05-13

## 1. Frontend Stack And Runtime

### Framework

- Next.js `16.2.4`
- React `19.2.4`
- React DOM `19.2.4`
- App Router under `src/app`
- TypeScript enabled
- Tailwind CSS v4 through `@tailwindcss/postcss`
- Icons through `lucide-react`
- Existing Prisma packages are installed, but Prisma is not used by any rendered page or component.

### Scripts

From `frontend/package.json`:

- `npm run dev`: `next dev --webpack`
- `npm run build`: `next build`
- `npm run start`: `next start`
- `npm run lint`: `eslint`

Note: `dev` currently uses webpack because default Turbopack dev mode was accepting TCP but not returning HTTP in this environment. Production build with Turbopack succeeds.

### Config Files

- `next.config.ts`
  - Sets `turbopack.root` to the frontend directory.
- `tsconfig.json`
  - Alias: `@/*` maps to `./src/*`.
  - JSX mode: `react-jsx`.
  - Strict TypeScript enabled.
- `postcss.config.mjs`
  - Uses `@tailwindcss/postcss`.
- `eslint.config.mjs`
  - Uses Next core web vitals and TypeScript rules.
- `README.md`
  - Still default create-next-app README.

### Global Styles

File: `src/app/globals.css`

- Imports Tailwind with `@import "tailwindcss";`
- Adds Tailwind source scan directive: `@source "../../";`
- CSS variables:
  - `--background: #ffffff`
  - `--foreground: #171717`
  - dark media mode changes background to `#0a0a0a` and foreground to `#ededed`
- Body:
  - uses `var(--font-inter)` and common system sans stack
  - `overflow-x: hidden`
- Tailwind theme tokens:
  - `--color-primary: #79b940`
  - `--color-secondary: #222222`
  - `--animate-fadeInUp: fadeInUp 1s ease-out forwards`
- Keyframe `fadeInUp`:
  - from `opacity: 0; transform: translateY(20px)`
  - to `opacity: 1; transform: translateY(0)`
